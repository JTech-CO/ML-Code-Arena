정사각 행렬의 행렬식을 가우스 소거법으로 계산하라.

행 연산으로 위삼각행렬을 만든 뒤 대각 성분을 모두 곱한다. 행을 교환할 때마다 부호가
한 번씩 뒤집힌다.

    det(A) = (-1)^(행 교환 횟수) · ∏ U[i][i]

수치 안정성을 위해 각 단계에서 **절댓값이 가장 큰 행을 피벗으로 올린다**(부분 피벗팅).

## 입력

    solve(a: np.ndarray) -> float

`a` 는 shape `(n, n)` 의 float 배열이며 `1 ≤ n ≤ 9` 다. 입력 배열을 제자리에서 고쳐도
된다 — 복사본이 전달된다.

## 예제

    solve(np.array([[4.0, 3.0],
                    [6.0, 3.0]]))

    ->  -6.0

## 주의

`numpy.linalg` 은 사용할 수 없다.

여인수 전개(라플라스 전개)로 풀면 `n!` 번의 연산이 필요하다. 소거법은 `n³` 이다.
`n ≤ 9` 라 둘 다 제한 안에 들지만, 실제 데이터에서 쓸 수 있는 것은 소거법뿐이다.

특이행렬(행렬식이 `0`)도 주어진다. 피벗이 `0` 이면 그 아래에 `0` 이 아닌 행이 없다는
뜻이므로 행렬식은 `0` 이다.
