`n` 개의 표본을 `k` 개의 겹으로 나누어 각 겹의 **검증 인덱스**를 반환하라. 순서는 섞지
않는다 — `0` 부터 차례대로 자른다.

`n` 이 `k` 로 나누어떨어지지 않으면 **앞쪽 `n % k` 개의 겹이 하나씩 더 갖는다**.
`sklearn.model_selection.KFold` 와 같은 규칙이다.

## 입력

    solve(n: int, k: int) -> list[np.ndarray]

`2 ≤ k ≤ n` 이다. 길이 `k` 의 리스트를 반환하며, 각 원소는 오름차순 정수 배열이다.
모든 배열을 합치면 `0 .. n-1` 이 정확히 한 번씩 나온다.

## 예제

    solve(7, 3)

    ->  [[0, 1, 2], [3, 4], [5, 6]]

`7 = 3 + 2 + 2` 다. 나머지가 `1` 이므로 첫 겹만 하나 더 갖는다.

    solve(6, 3)  ->  [[0, 1], [2, 3], [4, 5]]

## 주의

`numpy.array_split` 과 `numpy.split` 은 사용할 수 없다. `sklearn` 은 허용 목록 밖이다.

`n // k` 로만 자르면 뒤에 나머지가 남는다. 남은 것을 마지막 겹에 몰아 주는 것은
`sklearn` 규칙과 다르다 — **앞에서부터** 하나씩 나눠 준다.
