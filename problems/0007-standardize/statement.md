각 **열**에서 평균을 빼고 표준편차로 나눈 배열을 반환하라. 결과의 각 열은 평균 `0`,
표준편차 `1` 이 된다.

    z = (x - μ) / σ

표준편차의 분모는 **`n`** 이다 (모집단 표준편차, `ddof = 0`).

## 입력

    solve(x: np.ndarray) -> np.ndarray

`x` 는 shape `(n, p)` 의 float 배열이다. 표준편차가 `0` 인 상수 열은 주어지지 않는다.

## 예제

    solve(np.array([[1.0, 10.0],
                    [3.0, 20.0],
                    [5.0, 30.0]]))

    ->  [[-1.22474487, -1.22474487],
         [ 0.0       ,  0.0       ],
         [ 1.22474487,  1.22474487]]

첫 열의 평균은 `3.0`, 표준편차는 `sqrt(8/3) ≈ 1.63299` 다.

## 주의

`numpy.mean` · `numpy.std` · `numpy.var` 와 배열의 `.mean()` · `.std()` · `.var()`
메서드는 사용할 수 없다. `sum` 과 `sqrt` 로 직접 계산해야 한다.

**행이 아니라 열 단위**다. 그리고 `numpy.std` 의 기본값은 `ddof = 0` 이지만
`numpy.cov` 의 기본값은 `ddof = 1` 이다 — 이 문제는 `ddof = 0` 이다.
