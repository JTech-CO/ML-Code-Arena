## 무엇을 하는가

    MAE  = mean(|y - ŷ|)
    MSE  = mean((y - ŷ)²)
    RMSE = sqrt(MSE)
    R²   = 1 - SS_res / SS_tot

`SS_res` 는 잔차 제곱합, `SS_tot` 은 평균으로 예측했을 때의 제곱합이다. R² 는 "평균보다
얼마나 나은가"를 재며, 평균보다 못하면 음수가 된다.

## 왜 직접 구현하는가

MAE 와 RMSE 중 무엇을 쓸지는 **이상치를 어떻게 대할지**의 결정이다. 제곱은 큰 오차에
큰 벌점을 주므로 RMSE 는 이상치에 끌려간다. 같은 예측에서 두 값을 나란히 계산해 보면
그 차이가 수치로 보인다.

R² 가 음수일 수 있다는 것도 직접 계산해 봐야 받아들여진다 — 이름이 제곱이라 0 이상일
것 같지만 아니다.

## 흔한 실수

RMSE 를 MSE 의 평균으로 착각하는 것 — 제곱근은 평균을 낸 **뒤에** 취한다.
그리고 `SS_tot` 이 0 인 경우(정답이 전부 같은 값) R² 는 정의되지 않는다.
