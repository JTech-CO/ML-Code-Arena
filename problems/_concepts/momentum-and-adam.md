## 무엇을 하는가

**모멘텀**은 과거 이동을 기억한다. 골짜기를 지그재그로 내려가는 대신 관성으로 밀고 간다.

    v ← β v + g
    x ← x − lr · v

**Adam** 은 여기에 두 가지를 더한다. 기울기의 1차 적률(`m`)과 2차 적률(`v`)을 각각
지수이동평균으로 추적하고, 갱신량을 `sqrt(v)` 로 나눠 **파라미터마다 다른 학습률**을
만든다.

    m ← β₁ m + (1−β₁) g       m̂ = m / (1 − β₁ᵗ)
    v ← β₂ v + (1−β₂) g²      v̂ = v / (1 − β₂ᵗ)
    x ← x − lr · m̂ / (sqrt(v̂) + ε)

## 왜 직접 구현하는가

편향 보정(`1 − βᵗ`)이 왜 필요한지는 직접 짜면 1스텝에서 바로 보인다. `m` 을 0 에서
시작하므로 초기 몇 스텝은 실제 기울기보다 작게 나오고, 보정 없이는 학습 초반이 죽는다.
`t` 가 커지면 `βᵗ` 이 0 으로 가서 보정이 저절로 사라진다는 것도 확인할 수 있다.

## 흔한 실수

`ε` 을 제곱근 **안에** 넣는 것이다. `sqrt(v̂ + ε)` 와 `sqrt(v̂) + ε` 는 다르며 논문은
후자다. 그리고 `t` 를 0 부터 세는 것 — 1 부터 세야 한다. 0 이면 분모가 0 이 된다.
