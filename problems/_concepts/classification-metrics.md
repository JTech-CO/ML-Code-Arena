## 무엇을 하는가

혼동행렬은 실제와 예측을 2차원 표로 정리한다. 이진 분류에서는 네 칸이다.

    TP  실제 양성 · 예측 양성        FN  실제 양성 · 예측 음성
    FP  실제 음성 · 예측 양성        TN  실제 음성 · 예측 음성

여기서 지표들이 나온다.

    정밀도 = TP / (TP + FP)     예측이 양성일 때 맞을 확률
    재현율 = TP / (TP + FN)     실제 양성을 놓치지 않을 확률
    F1     = 2 · 정밀도 · 재현율 / (정밀도 + 재현율)

## 왜 직접 구현하는가

양성이 1% 인 데이터에서 전부 음성이라 답하면 정확도가 99% 다. 이 문장은 읽어서 알기보다
혼동행렬을 손으로 채워 봐야 몸에 남는다.

정밀도와 재현율이 왜 맞바꾸는 관계인지도 임계값을 바꿔 가며 계산해 보면 보인다.

## 흔한 실수

축을 뒤집는 것이다. 행이 실제인지 예측인지는 문서마다 다르므로 **문제의 정의를 따른다**.

분모가 0 인 경우 — 양성으로 예측한 것이 하나도 없으면 정밀도의 분모가 0 이다. 문제가
이때 무엇을 반환하라고 했는지 확인한다.
