## 무엇을 하는가

`Ax = b` 를 푸는 표준 방법은 가우스 소거법이다. 행 연산으로 `A` 를 위삼각행렬로 만든 뒤
아래에서 위로 대입해 나간다. 같은 소거 과정에서 대각 성분을 곱하면 행렬식이 나온다
(행 교환 횟수만큼 부호가 뒤집힌다).

## 왜 직접 구현하는가

**역행렬을 구해 곱하지 말라**는 조언은 어디서나 볼 수 있지만 이유는 잘 설명되지 않는다.
`inv(A) @ b` 는 `solve(A, b)` 보다 연산이 많고 오차가 크다. 소거를 직접 짜 보면 역행렬을
구하는 일이 `n` 개의 연립방정식을 푸는 것과 같다는 것이 보인다.

부분 피벗팅(각 단계에서 절댓값이 가장 큰 행을 위로 올리는 것)이 왜 필요한지도
피벗이 0 에 가까운 행렬을 직접 넣어 보면 안다.

## 흔한 실수

피벗이 정확히 0 일 때만 교환하는 것이다. 0 에 **가까울 때**도 교환해야 한다. 나눗셈의
분모가 작으면 오차가 증폭된다.
