## 무엇을 하는가

분류기는 보통 확률을 내놓고, 임계값을 정해야 판정이 된다. ROC 곡선은 임계값을 1 에서
0 까지 훑으며 거짓양성률(FPR)과 참양성률(TPR)의 궤적을 그린다.

    TPR = TP / (TP + FN)      FPR = FP / (FP + TN)

AUC 는 그 아래 면적이다. **무작위로 고른 양성 하나의 점수가 무작위로 고른 음성 하나보다
높을 확률**과 정확히 같다. 이 해석이 AUC 를 이해하는 가장 빠른 길이다.

## 왜 직접 구현하는가

AUC 는 임계값을 고르지 않고도 모델을 비교할 수 있게 해 준다. 곡선을 직접 그려 보면
왜 그런지 — 모든 임계값을 이미 다 훑었기 때문 — 이 자명해진다.

동점 점수 처리도 직접 짜야 만나는 문제다. 같은 점수가 여러 개면 곡선이 대각선으로
움직이고, 사다리꼴로 적분해야 정답이 나온다.

## 흔한 실수

계단 방식으로 면적을 더하는 것이다. 동점이 있으면 사다리꼴이어야 한다.
그리고 불균형 데이터에서 AUC 가 높다고 안심하는 것 — 그럴 때는 PR 곡선의 평균 정밀도가
더 정직하다.
