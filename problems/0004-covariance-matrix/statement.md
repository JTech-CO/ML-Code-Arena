데이터 행렬이 주어질 때 **특성 사이의 표본 공분산 행렬**을 계산하라.

행이 표본, 열이 특성이다. shape `(n, p)` 입력에 대해 결과는 `(p, p)` 다.

    C[i][j] = sum over t of (x[t][i] - μᵢ)(x[t][j] - μⱼ) / (n - 1)

`μᵢ` 는 `i` 번째 특성의 평균이다. 분모는 `n` 이 아니라 **`n - 1`** 이다 (표본 공분산).

## 입력

    solve(x: np.ndarray) -> np.ndarray

`x` 는 shape `(n, p)` 의 float 배열이며 `n ≥ 2` 다.

## 예제

    solve(np.array([[1.0, 2.0],
                    [2.0, 4.0],
                    [3.0, 6.0]]))

    ->  [[1.0, 2.0],
         [2.0, 4.0]]

각 열의 평균은 `2.0` 과 `4.0` 이고, 중심화하면 `[[-1,-2],[0,0],[1,2]]` 이다.

## 주의

`numpy.cov` 와 `numpy.corrcoef` 는 사용할 수 없다.

`numpy.var` 의 기본 분모는 `n` 이고 `numpy.cov` 의 기본 분모는 `n - 1` 이다. 이 문제는
`n - 1` 을 쓴다. 결과 행렬은 대칭이며 대각 성분은 각 특성의 표본 분산이다.
