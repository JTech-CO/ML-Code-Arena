평균 정밀도(AP)를 계산하라. 불균형 데이터에서 AUC 보다 정직한 지표다.

점수가 높은 순으로 하나씩 양성으로 판정해 나가며, 재현율이 **늘어난 순간**의 정밀도를
그 증가폭으로 가중해 더한다.

    AP = sum over k of (R[k] - R[k-1]) · P[k]

`P[k]` 와 `R[k]` 는 상위 `k` 개를 양성으로 판정했을 때의 정밀도와 재현율이다.
`R[0] = 0` 으로 둔다. 재현율이 늘지 않는 `k` 는 항이 `0` 이므로 더해도 그만이다.

## 입력

    solve(y_true: np.ndarray, scores: np.ndarray) -> float

`y_true` 는 `0` 또는 `1` 의 정수 배열, `scores` 는 같은 길이의 float 배열이다.
**점수에 동점은 없으며**, 양성이 최소 하나 있다.

## 예제

    solve(np.array([0, 1, 1, 0]),
          np.array([0.1, 0.9, 0.6, 0.4]))

    ->  1.0

점수 순은 `0.9(양성)`, `0.6(양성)`, `0.4(음성)`, `0.1(음성)` 이다. 상위 둘이 모두
양성이므로 `k = 1` 과 `k = 2` 에서 정밀도가 `1.0` 이고 재현율이 `0.5` 씩 늘어난다.

    solve(np.array([1, 0, 1]), np.array([0.9, 0.8, 0.7]))  ->  0.8333333333333333

`k = 1` 에서 `P = 1.0`, `ΔR = 0.5`. `k = 3` 에서 `P = 2/3`, `ΔR = 0.5` 다.

## 주의

`numpy.trapz` 계열은 사용할 수 없다. `sklearn.metrics` 는 허용 목록 밖이다.

**사다리꼴로 적분하지 않는다.** `sklearn.metrics.auc` 로 PR 곡선을 적분하면 AP 와 다른
값이 나온다. 이 문제의 정의는 위의 계단 합이다.

점수가 같은 표본은 주어지지 않으므로 동점 처리를 고민할 필요가 없다.
