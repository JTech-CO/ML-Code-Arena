Adam 옵티마이저의 **1스텝**을 계산하라.

    m ← β₁ m + (1 - β₁) g
    v ← β₂ v + (1 - β₂) g²

    m̂ = m / (1 - β₁ᵗ)
    v̂ = v / (1 - β₂ᵗ)

    θ ← θ - lr · m̂ / (sqrt(v̂) + ε)

`t` 는 **이번 스텝의 번호이며 1 부터 센다**. 인자로 주어지는 `t` 가 이미 그 값이다.

## 입력

    solve(params: np.ndarray, grads: np.ndarray,
          m: np.ndarray, v: np.ndarray, t: int,
          lr: float, beta1: float, beta2: float, eps: float)
        -> tuple[np.ndarray, np.ndarray, np.ndarray]

모두 shape `(n,)` 의 float 배열이다. `(새 params, 새 m, 새 v)` 를 이 순서로 반환한다.
반환하는 `m` 과 `v` 는 **편향 보정 전** 값이다 — 보정은 갱신에만 쓰고 상태로 남기지
않는다.

## 예제

    solve(np.array([1.0]), np.array([0.1]),
          np.array([0.0]), np.array([0.0]), 1,
          0.001, 0.9, 0.999, 1e-8)

    ->  ([0.999], [0.01], [1e-06])

`m = 0.1 × 0.1 = 0.01`, `v = 0.001 × 0.01 = 1e-6` 이다.
편향 보정하면 `m̂ = 0.01 / 0.1 = 0.1`, `v̂ = 1e-6 / 0.001 = 1e-3` 이고
`θ = 1.0 - 0.001 × 0.1 / (0.0316... + 1e-8) = 0.999` 다.

## 주의

`torch` 와 `tensorflow` 는 허용 목록 밖이다.

**`ε` 은 제곱근 밖에 더한다.** `sqrt(v̂ + ε)` 가 아니라 `sqrt(v̂) + ε` 다. 논문의 식이
후자이며, 두 형태는 `v̂` 가 작을 때 크게 갈린다.

`t` 를 `0` 으로 두면 `1 - β⁰ = 0` 이 되어 편향 보정에서 `0` 으로 나눈다.
`t` 가 커지면 `βᵗ` 이 `0` 으로 가서 보정이 저절로 사라진다.
