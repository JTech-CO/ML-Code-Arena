각 겹의 **클래스 비율이 전체와 같도록** `k` 개의 겹으로 나누어 검증 인덱스를 반환하라.

## 규칙

클래스 `0` 부터 차례로 처리한다. 각 클래스에 대해

1. 그 클래스에 속한 표본의 인덱스를 **오름차순**으로 모은다
2. 앞에서부터 겹 `0, 1, ..., k-1, 0, 1, ...` 로 **순환하며** 나눠 담는다

각 겹의 결과는 마지막에 오름차순으로 정렬한다.

## 입력

    solve(y: np.ndarray, k: int) -> list[np.ndarray]

`y` 는 `0` 이상의 정수 배열이다. 모든 클래스의 표본 수는 `k` 이상이다.
길이 `k` 의 리스트를 반환하며 각 원소는 오름차순 정수 배열이다.

## 예제

    solve(np.array([0, 0, 0, 0, 1, 1]), 2)

    ->  [[0, 2, 4], [1, 3, 5]]

클래스 `0` 의 인덱스 `[0,1,2,3]` 을 순환 배분하면 겹 0 이 `[0,2]`, 겹 1 이 `[1,3]` 이다.
클래스 `1` 의 인덱스 `[4,5]` 는 겹 0 이 `[4]`, 겹 1 이 `[5]` 다.

## 주의

`numpy.array_split` 과 `numpy.split` 은 사용할 수 없다. `sklearn` 은 허용 목록 밖이다.

**클래스마다 겹 0 부터 다시 시작한다.** 이전 클래스에서 이어서 돌리면 겹 크기가
`sklearn` 과 달라진다.

인덱스는 순환 배분한 뒤 **정렬해서** 반환한다. 넣은 순서 그대로 두면 클래스별로
묶여 나온다.
