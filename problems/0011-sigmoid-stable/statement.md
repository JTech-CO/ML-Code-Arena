시그모이드 함수를 원소별로 적용하라.

    σ(z) = 1 / (1 + exp(-z))

`z` 가 크게 음수이면 `exp(-z)` 가 오버플로한다. 부호에 따라 식을 나누면 `exp` 의 인자가
항상 `0` 이하가 되어 오버플로가 원리적으로 사라진다.

    z ≥ 0:  1 / (1 + exp(-z))
    z < 0:  exp(z) / (1 + exp(z))

두 식은 수학적으로 같다.

## 입력

    solve(z: np.ndarray) -> np.ndarray

`z` 는 임의 shape 의 float 배열이다. 성분의 절댓값은 최대 `1e4` 다. 결과 shape 은
입력과 같다.

## 예제

    solve(np.array([0.0, -1000.0, 1000.0]))

    ->  [0.5, 0.0, 1.0]

`-1000.0` 을 식 그대로 계산하면 `exp(1000)` 이 `inf` 가 되어 결과가 `0.0` 이 아니라
`nan` 이 된다.

## 주의

`numpy.tanh` 는 사용할 수 없다. `σ(z) = (tanh(z/2) + 1) / 2` 이므로 그대로 답이 된다.

`scipy` 는 허용 목록에 없다.

오버플로 경고가 떠도 채점은 계속된다. 표준 출력·표준 오류는 판정에 영향을 주지 않는다.
