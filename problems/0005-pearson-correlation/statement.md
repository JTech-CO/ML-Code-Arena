특성 사이의 **피어슨 상관계수 행렬**을 계산하라.

상관계수는 공분산을 두 표준편차로 나눈 값이며 항상 `-1` 과 `1` 사이다.

    R[i][j] = cov(xᵢ, xⱼ) / (σᵢ · σⱼ)

공분산과 표준편차 모두 분모에 `n - 1` 을 쓴다. 어차피 나눗셈에서 상쇄되므로 `n` 을 써도
값은 같다.

## 입력

    solve(x: np.ndarray) -> np.ndarray

`x` 는 shape `(n, p)` 의 float 배열이며 `n ≥ 2` 다. 표준편차가 `0` 인 상수 열은 주어지지
않는다.

## 예제

    solve(np.array([[1.0, 2.0],
                    [2.0, 1.0],
                    [3.0, 4.0],
                    [4.0, 3.0]]))

    ->  [[1.0, 0.6],
         [0.6, 1.0]]

## 주의

`numpy.corrcoef` 와 `numpy.cov` 는 사용할 수 없다.

대각 성분은 반드시 정확히 `1.0` 이 되어야 한다. 분자와 분모를 서로 다른 분모(`n` 과
`n - 1`)로 계산하면 대각이 `1.0` 에서 미세하게 벗어난다.
