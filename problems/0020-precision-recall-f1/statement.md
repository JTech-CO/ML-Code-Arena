이진 분류의 정밀도·재현율·F1 을 계산하라. 양성 클래스는 `1` 이다.

    정밀도 = TP / (TP + FP)
    재현율 = TP / (TP + FN)
    F1     = 2 · 정밀도 · 재현율 / (정밀도 + 재현율)

## 분모가 0 인 경우

세 값 모두 **분모가 `0` 이면 `0.0` 을 반환한다**. 양성으로 예측한 것이 하나도 없으면
정밀도의 분모가 `0` 이고, 실제 양성이 하나도 없으면 재현율의 분모가 `0` 이다.

## 입력

    solve(y_true: np.ndarray, y_pred: np.ndarray) -> tuple[float, float, float]

두 배열 모두 `0` 또는 `1` 로 이루어진 shape `(n,)` 정수 배열이며 `n ≥ 1` 다.
`(정밀도, 재현율, F1)` 을 이 순서로 반환한다.

## 예제

    solve(np.array([1, 1, 0, 0]),
          np.array([1, 0, 1, 0]))

    ->  (0.5, 0.5, 0.5)

`TP = 1`, `FP = 1`, `FN = 1` 이다.

## 주의

`sklearn.metrics` 는 허용 목록 밖이다.

정밀도와 재현율을 바꿔 쓰기 쉽다. **정밀도의 분모는 예측 양성 수**, **재현율의 분모는
실제 양성 수**다. 둘이 같은 데이터에서는 값이 같아 구분되지 않는다.

`0` 으로 나누면 `nan` 이 나오고, `nan` 은 어떤 값과도 같지 않으므로 채점에서
`value_mismatch` 가 된다.
