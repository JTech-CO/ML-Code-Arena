연립일차방정식 `Ax = b` 의 해 `x` 를 가우스 소거법으로 구하라.

전진 소거로 `A` 를 위삼각행렬로 만들고, 아래에서 위로 후진 대입한다. 각 단계에서
**절댓값이 가장 큰 행을 피벗으로 올린다**(부분 피벗팅).

## 입력

    solve(a: np.ndarray, b: np.ndarray) -> np.ndarray

`a` 는 shape `(n, n)`, `b` 는 shape `(n,)` 의 float 배열이다. `a` 는 항상 정칙이며
`1 ≤ n ≤ 40` 이다. 결과 shape 은 `(n,)` 다.

## 예제

    solve(np.array([[2.0, 1.0],
                    [1.0, 3.0]]),
          np.array([3.0, 5.0]))

    ->  [0.8, 1.4]

## 주의

`numpy.linalg` 은 사용할 수 없다.

**역행렬을 구해 곱하지 않는다.** `inv(A) @ b` 는 소거법보다 연산이 많고 오차가 크다.
역행렬을 구하는 일 자체가 `n` 개의 연립방정식을 푸는 것과 같다.

피벗팅을 생략해도 이 문제의 케이스는 통과한다. 그래도 넣는 편이 좋다 — 피벗이 `0` 에
가까우면 나눗셈에서 오차가 증폭된다.
