k-최근접 이웃으로 질의 점들의 클래스를 예측하라. 거리는 유클리드 거리다.

## 동점 규칙

두 곳에서 동점이 생길 수 있다. 규칙을 정확히 따라야 한다.

- **거리 동점** — 거리가 같으면 **훈련 데이터에서의 인덱스가 작은 쪽**을 먼저 고른다
- **투표 동점** — 최다 득표 클래스가 여럿이면 **레이블이 작은 쪽**을 고른다

## 입력

    solve(train_x: np.ndarray, train_y: np.ndarray,
          queries: np.ndarray, k: int, n_classes: int) -> np.ndarray

`train_x` 는 shape `(n, p)`, `train_y` 는 shape `(n,)` 의 정수 배열이다.
`queries` 는 shape `(m, p)` 이고, `1 ≤ k ≤ n` 이다.
결과는 shape `(m,)` 의 정수 배열이다.

## 예제

    solve(np.array([[0.0, 0.0], [1.0, 1.0], [2.0, 2.0]]),
          np.array([0, 0, 1]),
          np.array([[0.1, 0.1], [2.1, 2.1]]),
          1, 2)

    ->  [0, 1]

## 주의

`numpy.linalg` 은 사용할 수 없다. `sklearn` 은 허용 목록 밖이다.

거리를 **비교만** 한다면 제곱근을 생략해도 순서가 같다. 이 문제는 거리 자체를
반환하지 않으므로 생략해도 된다.

정렬은 안정 정렬이어야 인덱스 동점 규칙이 지켜진다 —
`numpy.argsort` 의 기본 알고리즘은 안정 정렬이 아니다.
