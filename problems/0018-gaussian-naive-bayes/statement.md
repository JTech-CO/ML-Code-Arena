가우시안 나이브 베이즈로 질의 점들의 클래스를 예측하라.

## 학습

각 클래스 `c` 마다 사전확률과 특성별 평균·분산을 구한다.

    P(c)   = (클래스 c 의 표본 수) / n
    μ[c,j] = 클래스 c 표본의 j 번째 특성 평균
    σ²[c,j] = 클래스 c 표본의 j 번째 특성 분산 (분모 n_c, 즉 ddof = 0)

분산이 `0` 이 되는 것을 막기 위해 **모든 분산에 `1e-9` 를 더한다**.

## 예측

확률을 곱하면 언더플로하므로 로그로 더한다.

    log P(c | x) ∝ log P(c) + sum over j of [ -0.5 log(2π σ²[c,j]) - (xⱼ - μ[c,j])² / (2 σ²[c,j]) ]

가장 큰 값을 갖는 클래스를 고른다. 동점이면 **레이블이 작은 쪽**이다.

## 입력

    solve(train_x: np.ndarray, train_y: np.ndarray,
          queries: np.ndarray, n_classes: int) -> np.ndarray

`train_x` 는 shape `(n, p)`, `train_y` 는 `0` 이상 `n_classes` 미만의 정수 배열이다.
모든 클래스에 표본이 최소 하나씩 있다. 결과는 shape `(m,)` 의 정수 배열이다.

## 예제

    solve(np.array([[0.0], [0.2], [5.0], [5.2]]),
          np.array([0, 0, 1, 1]),
          np.array([[0.1], [5.1]]),
          2)

    ->  [0, 1]

## 주의

`numpy.bincount` · `numpy.unique` 는 사용할 수 없다. `sklearn` 은 허용 목록 밖이다.

**확률을 그대로 곱하지 않는다.** 특성이 20개만 되어도 곱이 `0` 으로 언더플로하며,
그 결과 모든 클래스의 점수가 `0` 이 되어 항상 같은 답이 나온다.

분산의 분모는 `n_c` 다 (`ddof = 0`). 표본 분산(`n_c - 1`)을 쓰면 클래스마다 다르게
어긋난다.
