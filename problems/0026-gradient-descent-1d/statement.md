2차 함수 `f(x) = a x² + b x + c` 에 경사하강법을 적용하고 **궤적 전체**를 반환하라.

    f'(x) = 2 a x + b
    x ← x - lr · f'(x)

## 입력

    solve(a: float, b: float, c: float,
          x0: float, lr: float, steps: int) -> np.ndarray

`steps` 번 갱신하며, 반환 배열의 길이는 **`steps + 1`** 이다. 첫 원소는 `x0` 이고
마지막 원소는 마지막 갱신 결과다.

`c` 는 기울기에 영향을 주지 않지만 인자로 주어진다.

## 예제

    solve(1.0, 0.0, 0.0, 1.0, 0.1, 3)

    ->  [1.0, 0.8, 0.64, 0.512]

`f(x) = x²` 이므로 `f'(x) = 2x` 이고, 매 스텝 `x ← x - 0.1 · 2x = 0.8x` 다.

## 주의

`numpy.polyder` · `numpy.polyval` · `numpy.roots` 는 사용할 수 없다. `scipy.optimize` 는
허용 목록 밖이다.

**학습률이 큰 케이스가 주어진다.** `lr > 1/a` 면 발산한다. 발산하는 궤적도 그대로
반환한다 — 값을 자르거나 멈추지 않는다.

기울기의 **반대** 방향으로 간다. 부호를 뒤집으면 최솟값에서 멀어진다.
