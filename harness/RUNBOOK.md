# RUNBOOK.md — 런북 (증상 → 원인 → 조치)

> 아래 1~11은 어떤 프로젝트에나 흔한 일반 행이고, 20번대는 이 프로젝트 고유 행이다. 새 이슈는 처음 겪을 때 임시 처치 후 `PROGRESS.md`에 기록하고, 반복되면 여기 행으로 승격한다. 불변식 관련 증상은 조치에 INV-n를 함께 적는다.

| # | 증상 | 흔한 원인 | 조치 |
|---|---|---|---|
| 1 | 환경/의존성 설치 실패 | 버전 불일치, 락파일 깨짐, 플랫폼 차이 | `docs/ENVIRONMENT.md`대로 재설치, 버전·소스 고정 |
| 2 | 빌드/타입체크 실패 | 타입 불일치, 설정·경로 오류 | 에러 위치부터 좁혀 수정 |
| 3 | 테스트 불안정(flaky) | 시간·순서·외부 의존, 시드 미고정 | 시드 고정, 외부 의존 격리, 결정론 확보 |
| 4 | 정합성 실패 | 두 구현의 정규화·순서 차이 | 단일 기준 문서로 양측 정렬 |
| 5 | "돌지만 효과 없음" | 전제 미충족, 신호 누락 | 초소형 케이스로 로직부터 검증 |
| 6 | 수치 발산/폭주(NaN 등) | 스케일 과대, 식 오류 | 스케일·정규화 점검, 핵심 식 재검토 |
| 7 | 처리 느림 | 직렬 병목, 배치 미적용 | 병렬화, 핫스팟 프로파일링 |
| 8 | 경계 위반 lint 에러 (INV-3) | 모듈 간 금지된 상호 import | 경계 준수, 공유는 `packages/shared`만 |
| 9 | 외부 연동이 갑자기 깨짐 | 대상 API/스키마 변경 | 계약 파일 한 곳만 갱신 |
| 10 | 환경별 동작 차이 | 환경변수·경로·버전·권한 차이 | 환경 동등성 확보 |
| 11 | 통신/연결 실패(CORS·프록시) | 출처 허용 누락, 경로 불일치 | 허용 출처·경로·프록시 설정 점검 |
| 20 | 제출이 `PENDING`에서 멈춤 | 워커 미기동, Redis 연결 실패, 큐 이름 불일치 | 워커 로그 확인 → Redis 연결 → 큐 이름 상수 일치 확인 |
| 21 | 모든 제출이 `IE` | 컨테이너 이미지 없음, Docker 소켓 권한 없음, 마운트 경로 오류 | `docker images`로 이미지 확인 → 소켓 권한 → 마운트 절대경로 확인. **격리 옵션 완화로 해결하지 않는다**(INV-4) |
| 22 | `TLE`가 비정상적으로 다발 | 컨테이너 콜드 스타트가 시간 제한에 포함됨, CPU 제한 과소, 이미지 미리 pull 안 됨 | 시간 측정을 러너 내부 기준으로 분리, 워커 기동 시 이미지 사전 pull |
| 23 | 정답 코드인데 `FBD` | `allowed_imports` 화이트리스트 누락, 표준 라이브러리 미등록 | `problem.json`의 `allowed_imports` 보완. 블랙리스트가 아니라 **화이트리스트가 우선**임에 주의 |
| 24 | 정답 코드인데 `WA` | 기대값을 손으로 작성함(INV-10), dtype/shape 불일치, `rtol` 과소 | `problem-sync --verify`로 기대값 재생성 → shape·dtype 대조 → 허용 오차 재검토 |
| 25 | 사용자 코드의 부작용이 실행됨 | AST 검사가 import 뒤에 있음 | 러너 실행 순서 복구(INV-6). 검사 → import 순서 |
| 26 | 연속 제출에서 이전 결과가 섞임 | 컨테이너 재사용, `/tmp` 잔존 | 제출당 컨테이너 생성 확인(INV-8) |
| 27 | SSE 연결이 주기적으로 끊김 | 리버스 프록시 버퍼링·타임아웃 | `X-Accel-Buffering: no`, 프록시 read timeout 연장, 하트비트 주석 프레임 전송 |
| 28 | 익명 10문제 제한이 안 걸림 | 쿠키 `SameSite`/`Secure` 설정, 카운트를 클라이언트에서 계산 | 서버 카운트로 이동(INV-9), 쿠키 속성 점검 |
| 29 | 익명 사용자가 로그인해도 기록이 사라짐 | 승계 쿼리 미실행, 쿠키가 로그인 시 먼저 삭제됨 | 승계를 로그인 트랜잭션 안에서 실행, 쿠키 삭제는 승계 이후 |
| 30 | 테마 전환 시 첫 화면이 깜빡임 | `<head>` FOUC 방지 인라인 스크립트 누락 | `docs/DESIGN.md` §8.2 스크립트를 CSS·번들보다 앞에 배치 |
| 31 | 다크 모드에서 판정 색이 안 보임 | 라이트 토큰을 그대로 사용 | 다크 전용 판정 토큰 적용, 대비 검사 재실행(INV-12) |
| 32 | 문제 목록이 느림 | 정답률을 매 요청마다 전체 제출로 집계 | `solved` 테이블·집계 캐시 사용, 인덱스 확인 |
| 40 | Postgres 가 "superuser password is not specified" 로 기동 거부 | compose 의 `${...}` 보간이 **compose 파일 옆** `.env` 를 읽는다. 우리 `.env` 는 저장소 루트다 | `docker compose --env-file .env -f deploy/compose.yml ...` 로 부른다 (ENVIRONMENT §7.3). `env_file:` 은 컨테이너 환경변수용이라 보간을 대신하지 못한다 |
| 41 | `/health` 가 200 인데 JSON 이 아니라 HTML | 프록시에 `/health` 경로가 없어 SPA 폴백이 `index.html` 을 돌려준다. **API 가 죽어도 헬스체크가 초록** | `Caddyfile` 에 `handle /health { reverse_proxy api:3000 }` 을 둔다. 모니터링은 본문까지 확인할 것 |
| 42 | 이미지 빌드가 "vite 를 찾을 수 없다"로 실패 | `.dockerignore` 부재로 호스트 `node_modules`(pnpm 심볼릭 링크 농장)가 컨텍스트에 들어가 컨테이너 링크를 덮어씀 | `.dockerignore` 에 `node_modules` 추가. 같은 이유로 `.env` 도 반드시 제외한다(INV-1) — 없으면 시크릿이 이미지 레이어에 박힌다 |
| 43 | 개발 DB 의 데이터가 테스트 후 사라짐 | API 테스트가 `DATABASE_URL` 대상에 `TRUNCATE` 를 건다 | `pnpm test` 는 `<db>_test` 를 쓴다. 이름이 `_test` 로 끝나지 않으면 거부한다. 운영 호스트에서 테스트를 돌리지 않는다 |
| 44 | 새 배포가 브라우저에 반영되지 않음 | `index.html` 이 캐시됨. 경로 매처를 `/index.html` 로 적으면 요청 경로가 `/` 일 때 매치되지 않는다 | `@page not path /assets/*` 로 매처를 뒤집어 `no-cache` 를 건다. 해시 붙은 자산만 `immutable` |
| 45 | 백업은 도는데 복구가 안 됨 | 덤프 생성만 확인하고 복원을 확인하지 않음 | `tools/db-backup.js --verify` 를 크론에 넣는다 — 빈 DB 에 실제 복원 후 행 수를 대조하고 그 DB 를 지운다 |
| 46 | `IE` 경보가 떴는데 원인을 모름 | `IE` 상세가 저장되지 않음 | `submissions.ie_reason` 을 본다 (migration 0005). API 로는 나가지 않는 운영 전용 컬럼이다 |

## 행 추가 규칙
같은 이슈를 2회 이상 겪으면 행으로 승격. 형식: 증상(관측 가능) / 가장 흔한 원인 순 / 최소 조치. 불변식 관련이면 INV-n 병기.
