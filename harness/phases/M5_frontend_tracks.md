## DoD (완료 게이트)
1. 문제 선택 → 코드 작성 → 제출 → 판정 수신 전체 흐름이 수동 시연으로 완주된다.
2. **판정 8종이 UI에 전부 정확히 표시된다.** 빈 칸·`undefined`가 없다.
3. `WA` 시 `ShapeDiff`가 기대/실제 shape를 표시하고, **기대값 자체는 표시하지 않는다**(INV-5 준수).
4. 흑백 렌더에서 판정 구분이 가능하다(INV-11 준수) — 판정 코드 텍스트가 항상 병기됨.
5. 문제 목록 첫 화면에 **15행 이상**이 보인다(1920×1080 기준).
6. SSE 실시간 제출이 갱신되고 익명 제출은 표시되지 않는다.
7. 개념 ↔ 문제 이동이 양방향 모두 1클릭이다.
8. `AnonQuotaBar`가 잔여 3개 이하에서만 노출되고, 닫기가 동작한다.
9. 반응형: 1280 / 1024 / 768 / 375px에서 가로 스크롤이 없다.
10. 키보드만으로 문제 선택·진입·제출(`Ctrl/Cmd+Enter`)이 가능하고 포커스 표시가 항상 보인다.
11. 판정 결과 영역이 `role="status"` + `aria-live="polite"` 로 안내된다.
12. `docs/DESIGN.md` §12 금지 목록 12항목이 전부 0건.

## 롤백 계획
컴포넌트 단위 커밋. 라우트별로 분리해 특정 트랙만 되돌릴 수 있게 둔다.

## 리스크 / 미지수
- CodeMirror 6 다크 테마와 토큰 정합 — 에디터 배경이 `--bg-canvas`와 어긋나면 화면이 쪼개져 보인다.
- 스플리터 드래그가 모바일에서 필요 없으므로 1024px 미만은 탭 전환으로 완전히 대체한다.

## 주의
- 제한 칩을 툴팁·아코디언 뒤에 숨기지 않는다. `FBD` 판정의 대부분은 제한을 못 본 데서 나온다.
- 채점 대기를 스피너로 표시하지 않는다. `채점 중 · 대기 3번째` 처럼 정보를 준다.
- 판정 색을 배경 뱃지로 칠하지 않는다. 목록 밀도가 무너진다.
