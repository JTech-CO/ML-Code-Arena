## 이 프로젝트의 특수성 (먼저 읽기)

채점 대상은 **신뢰할 수 없는 코드**다. 일반 웹 앱이 아니라 사용자가 보낸 임의의 Python을 실행하는 시스템이다. 따라서 검증 우선순위가 일반 프로젝트와 다르다.

> 격리·비노출 불변식 > 채점 정확성 > 핵심 기능 실효 > 통합 정합성 > UX/배포

격리가 깨지면 채점이 아무리 정확해도 서비스를 열 수 없다. 격리 옵션을 완화해야 진행되는 상황은 설정 문제가 아니라 설계 문제이며, STOP 대상이다.
