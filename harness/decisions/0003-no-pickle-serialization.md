# ADR-0003: 테스트케이스 직렬화에 pickle 대신 `.npz`/JSON을 쓴다

- **상태**: 채택
- **일시**: 2026-08-05
- **관련**: M1, M6, INV-7, `docs/TECHNICAL.md` §4.2.1

## 맥락
numpy 배열을 담은 테스트케이스를 컨테이너에 전달해야 한다. Python 생태계의 기본 선택지는 pickle이고 numpy 객체를 그대로 담을 수 있어 편리하다.

## 결정
pickle을 사용하지 않는다. 배열은 `.npz`, 스칼라·구조체는 JSON으로 직렬화한다. 러너의 로더는 허용된 포맷만 읽는다.

## 근거
pickle 역직렬화는 임의 코드 실행이 가능하다. 테스트케이스 파일은 채점 컨테이너라는 **신뢰 경계 안으로 들어가는 데이터**이므로, 파일이 오염되면 격리 자체가 무의미해진다. 지금은 우리가 만든 파일만 넣지만, Phase 2에서 데이터셋 스토리지가 생기면 경계가 넓어진다. 그때 바꾸는 비용보다 지금 제약하는 비용이 싸다.

## 결과 / 트레이드오프
- 이득: 역직렬화 공격면 제거, 포맷이 사람이 읽을 수 있어 디버깅 용이.
- 비용: 임의 Python 객체를 기대값으로 쓸 수 없다. dict·list·ndarray·스칼라로 표현 가능한 범위로 제한된다.

## 검토한 대안
- **pickle + 서명 검증** — 서명 키 관리가 늘고, 키 유출 시 방어가 무너진다. 기각.
- **JSON 단독** — 큰 부동소수점 배열에서 정밀도 손실과 파일 크기 문제. `.npz` 병용으로 해결.
