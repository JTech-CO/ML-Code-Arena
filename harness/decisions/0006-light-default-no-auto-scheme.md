# ADR-0006: `prefers-color-scheme`을 자동 적용하지 않고 라이트를 기본값으로 고정한다

- **상태**: 채택
- **일시**: 2026-08-05
- **관련**: M4, INV-12, `docs/DESIGN.md` §8.1

## 맥락
다크 모드를 지원할 때 흔한 기본 동작은 OS 설정(`prefers-color-scheme`)을 따르는 것이다. 그러나 이 프로젝트의 요구는 "기본은 라이트"다.

## 결정
`prefers-color-scheme`을 읽지 않는다. `localStorage`에 사용자가 명시적으로 선택한 값이 있을 때만 다크를 적용하고, 없으면 항상 라이트로 렌더한다.

## 근거
OS 다크 설정 사용자가 첫 방문에서 자동으로 다크로 들어가면 "기본은 라이트"라는 요구가 무의미해진다. 다크 사용자 비율이 낮지 않으므로 실질적으로 기본값이 둘로 갈라진다. 제품이 어떤 모습으로 처음 보이는지는 결정되어 있어야 한다.

## 결과 / 트레이드오프
- 이득: 첫인상이 일관됨. 스크린샷·문서·지원 대응이 단일 기준을 갖는다.
- 비용: OS 다크 사용자가 첫 방문에서 밝은 화면을 본다. 토글이 상단에 상시 노출되므로 전환 비용은 1클릭이다.

## 검토한 대안
- **OS 설정 자동 적용** — 요구사항과 충돌. 기각.
- **첫 방문만 OS 설정 참조 후 저장** — 결과적으로 자동 적용과 같다. 기각.

## 주의
이 결정은 FOUC 방지 인라인 스크립트를 필수로 만든다. 저장값 확인이 CSS·번들보다 먼저 실행되지 않으면 다크 사용자가 매 새로고침마다 흰 화면 깜빡임을 본다(런북 30번).
