# CLAUDE.md — ML Code Arena 에이전트 계약

> Claude Code가 세션마다 자동으로 읽는 최우선 문서. 여기 규칙이 다른 모든 지시에 우선한다. 상세 절차는 `HARNESS.md`, 불변식 본문은 `INVARIANTS.md`.

## 프로젝트 한 줄
AI/머신러닝/딥러닝 알고리즘을 라이브러리 없이 직접 구현하게 하는 온라인 저지 플랫폼. Phase 1은 Python 단일 언어·CPU 전용·`tolerance`+`structural` 2개 채점 모드·문제 30개로 한정한다.

## 매 세션 행동
1. 먼저 `PROGRESS.md`를 읽어 현재 phase·다음 할 일·미결을 파악한다.
2. **한 번에 한 phase.** 해당 `phases/Mn.md`의 진입조건(DoR)을 만족할 때만 시작한다.
3. **완료 = 측정 가능한 게이트(DoD) 전부 통과.** "에러 없이 돈다"는 완료가 아니다.
4. 게이트 통과를 주장할 때는 **명령과 출력을 증거로** phase 파일/`PROGRESS.md`에 남긴다.
5. 종료 시 `PROGRESS.md`를 갱신하고 커밋한다.

## 이 프로젝트의 성격 (오판 방지)
채점 대상은 **신뢰할 수 없는 코드**다. 일반 웹 앱이 아니라 사용자가 보낸 임의의 Python을 실행하는 시스템이다. 편의를 위한 우회가 곧 보안 사고가 된다. 격리·비노출 관련 불변식(INV-4~INV-8)은 "나중에 강화"의 대상이 아니라 M1부터 성립해야 하는 전제다.

## 레드라인 (절대 금지 — 위반 시 즉시 멈춤)
- 채점 컨테이너의 **네트워크 차단 해제**(INV-4). 디버깅 편의를 위해서도 안 된다.
- 기대값(expect)을 **API 응답·에러 메시지·로그에 노출**(INV-5).
- AST 정적 검사를 사용자 코드 import **이후로 이동**(INV-6).
- 테스트케이스 직렬화에 **pickle 사용**(INV-7).
- 익명 제한 카운트를 **클라이언트 값으로 신뢰**(INV-9).
- 테스트 삭제·약화 또는 게이트 수치 임의 하향으로 "통과" 위장.
- 불변식이 깨진 채 다음 phase 진행.
- 아키텍처·패키지 경계 임의 변경(사용자 승인 없이). 경계는 `docs/FILE_TREE.md`.
- 시크릿(`.env`)·대용량 산출물 커밋.
- Phase 1 제외 범위(`docs/TECHNICAL.md` §2.2) 기능을 임의로 추가. 특히 학습 문제·GPU·Go/R.

## 멈춤(STOP) — 다음이면 작업을 멈추고 보고한다
- 같은 실패를 서로 다른 방법으로 3회 시도해도 미해결.
- DoD 게이트를 못 넘는데 우회 충동.
- 불변식을 깨야만 통과 가능.
- 큰 아키텍처 변경이 필요해 보임 / 외부 제약(자원·접근·약관).
- Docker 소켓 권한·격리 옵션을 완화해야 진행되는 상황.
→ 멈출 때 절차는 `HARNESS.md` §2.
